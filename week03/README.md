# Week 03 — Combinational Circuit

## 파일 구성

| 파일 | 내용 |
|---|---|
| `src/comparator_4bit.v` | 관계 연산자로 기술한 4비트 비교기 |
| `src/decoder_3to8.v` | case문으로 기술한 3-to-8 디코더 |
| `src/priority_encoder_4to3.v` | `d[3]` 최우선인 4-to-3 우선순위 인코더 |
| `src/mux_8to1.v` | 입력 데이터가 4비트인 8-to-1 멀티플렉서 |
| `sim/tb_comparator_4bit.v` | 교안 6.2.1 ~ 6.2.4 |
| `sim/tb_decoder_3to8.v` | input `3'b000` ~ `3'b111` |
| `sim/tb_priority_encoder_4to3.v` | 교안 6.6.1 ~ 6.6.5 |
| `sim/tb_mux_8to1.v` | sel `3'b000` ~ `3'b111` |

## 포트

| 모듈 | 입력 | 출력 |
|---|---|---|
| `comparator_4bit` | `a[3:0]`, `b[3:0]` | `gt`, `eq`, `lt` |
| `decoder_3to8` | `x`, `y`, `z` | `d[7:0]` |
| `priority_encoder_4to3` | `d[3:0]` | `x`, `y`, `v` |
| `mux_8to1` | `d0` ~ `d7` (각 4비트), `sel[2:0]` | `y[3:0]` |

## 시뮬레이션 케이스

**`comparator_4bit`**

| A | B | gt | eq | lt |
|---|---|---|---|---|
| `4'b0011` | `4'b1000` | 0 | 0 | 1 |
| `4'b0111` | `4'b0001` | 1 | 0 | 0 |
| `4'b1001` | `4'b1001` | 0 | 1 | 0 |
| `4'b1011` | `4'b1111` | 0 | 0 | 1 |

**`priority_encoder_4to3`** — `d[3]` > `d[2]` > `d[1]` > `d[0]`

| d | x | y | V |
|---|---|---|---|
| `4'b0000` | 0 | 0 | 0 |
| `4'b1000` | 1 | 1 | 1 |
| `4'b1011` | 1 | 1 | 1 |
| `4'b0101` | 1 | 0 | 1 |
| `4'b0001` | 0 | 0 | 1 |

**`mux_8to1`** — 테스트벤치가 설정하는 입력 데이터

| 입력 | 값 | 입력 | 값 |
|---|---|---|---|
| `d0` | `4'b0011` | `d4` | `4'b0110` |
| `d1` | `4'b0101` | `d5` | `4'b1010` |
| `d2` | `4'b1001` | `d6` | `4'b1111` |
| `d3` | `4'b1100` | `d7` | `4'b0001` |

## 논리식

`priority_encoder_4to3` 의 카르노맵 유도 결과.

| 출력 | 논리식 |
|---|---|
| x | `D3 + D2` |
| y | `D3 + D2' · D1` |
| V | `D3 + D2 + D1 + D0` |
